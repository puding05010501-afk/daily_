# 👕 오늘뭐입지 — 날씨별 코디 추천

날짜와 지역을 고르면 그날의 기온·체감온도·강수·바람·자외선을 불러와 옷차림을 추천해 주는 웹사이트입니다.
날씨 데이터는 [Open-Meteo](https://open-meteo.com/)를 사용하며 **API 키가 필요 없습니다.**

## 주요 기능
- 📍 도시 검색(한글 지원) 및 현재 위치 사용
- 📅 날짜 선택: 1940년 ~ 16일 후까지 (과거는 관측 기록, 미래는 예보)
- 🌡️ 최고/최저 기온, 체감 평균, 강수 확률, 일교차, 풍속, 자외선
- 👕 체감 평균기온 기준 8단계 코디 추천 (아우터·상의·하의·신발·소품)
- ☂️ 비·눈·큰 일교차·강풍·강한 자외선에 따른 추가 아이템과 팁
- 📈 시간대별 기온 그래프, 전날 대비 기온 변화

## GitHub Codespaces에서 실행하기
1. 이 폴더의 파일을 GitHub 저장소에 올립니다 (`.devcontainer` 폴더 포함).
2. 저장소 페이지에서 **Code → Codespaces → Create codespace on main** 클릭
3. 준비가 끝나면 서버(포트 8000)가 자동으로 켜지고 미리보기가 열립니다.

자동으로 열리지 않으면 터미널에서 직접 실행하세요.

```bash
python3 -m http.server 8000
```

그다음 아래쪽 **PORTS** 탭에서 8000번 포트의 🌐 아이콘을 눌러 브라우저로 엽니다.

## 파일 구성
```
index.html                 화면 구조
style.css                  디자인 (다크 모드·모바일 대응)
script.js                  날씨 API 호출, 코디 추천 로직, 그래프
.devcontainer/             Codespaces 자동 실행 설정
```

## 코디 기준 바꾸기
`script.js`의 `BANDS` 배열에서 기온 구간별 추천 옷을 자유롭게 수정할 수 있습니다.
